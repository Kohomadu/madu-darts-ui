# Autodarts-shaped client; Manual Override is local-only

Madu Darts UI is a browser client of an Autodarts 2.1–shaped local detection HTTP/WebSocket API. **v1 ships playable against Winmau Autodarts Detection only** (typical port 3180): live Hits/Turns, Detection Accuracy, and Training Game **101**.

Winmau Autodarts Detection does not accept player Manual Overrides from this UI. Corrections therefore live **only in the UI** for the open Turn: they drive the Board strip, **101** scoring, and Detection Accuracy, and they are not PATCHed back to the box. When Autodarts keeps streaming the uncorrected Segment, the UI keeps the local correction until the Turn clears. Undo of the last sealed Turn is local in the same way: the strip shows the Segments the UI sealed with, the player can Manual Override them, and confirming reseals scoring and Detection Accuracy without asking Autodarts to rewrite history. Reset board is the control that calls the box: `POST /api/reset` clears a stuck takeout there, and this UI does not rewrite its own sealed Turns when that call returns. Next score uses the same call and, only when it succeeds, advances the local 101 target (or ends the run on 170) while holding the strip empty until the stream itself is empty. Madu darts detection (later) may reopen write-back overrides; that is a deliberate future change, not v1 behaviour.
